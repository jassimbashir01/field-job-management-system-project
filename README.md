# Field Job Management System

Job-first field service management for trade and service companies. Admin
and manager web application, plus an offline-capable technician PWA — with
optional quoting, invoicing, and staff scheduling built in.

**Status:** in development. See `docs/` for architecture and setup.

## Stack

Next.js · TypeScript · Tailwind CSS · shadcn/ui · PostgreSQL · Drizzle ORM ·
S3-compatible object storage · Service Worker + IndexedDB offline sync

## Development

​`bash
pnpm install
cp .env.example .env.local
pnpm dev
​`
